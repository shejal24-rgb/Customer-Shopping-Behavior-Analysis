## 📌 Project Overview

This project analyzes customer shopping behavior using Python.
It explores purchasing patterns, customer preferences, product
performance, payment methods and revenue trends.

## 🎯 Project Objectives

- Understand customer purchasing behavior.
- Analyze category-wise revenue.
- Compare male and female shopping patterns.
- Identify popular products.
- Analyze monthly shopping trends.
- Understand customer age groups.
- Evaluate payment method preferences.

## 🛠️ Technologies Used

- Pandas
- NumPy
- Matplotlib
- Seaborn

The analysis helps businesses understand:

- Which product categories generate the most revenue.
- Which customer groups contribute more sales.
- Which payment methods generate the most revenue.
